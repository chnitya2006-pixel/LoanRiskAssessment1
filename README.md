# 💰 Intelligent Loan Risk Assessment System

## 📌 Project Overview

The Intelligent Loan Risk Assessment System is a Machine Learning based application that predicts whether a loan application is likely to be approved or not.

The system takes important applicant details as input and uses a trained Machine Learning model to provide a loan approval prediction.

## 🎯 Objective

The main objective of this project is to use Machine Learning to assist in evaluating loan applications quickly and efficiently.

## 📊 Input Features

The system uses the following five features:

- Age
- Annual Income
- Credit Score
- Loan Amount
- Loan Duration

## 🤖 Machine Learning Model

- Algorithm: Random Forest Classifier
- Dataset: Financial Risk for Loan Approval
- Dataset Size: 20,000 records
- Model Accuracy: 86.875%
